## Proposed partner-funded pilot
One bounded historical, de-identified or non-sensitive dataset supplied by partner with written analysis permission, source tables, independent replicate identifiers, condition metadata and recovery endpoints. Scope and computational feasibility assessed before contracting; no patient-level data requested. No proprietary data on public GitHub.

Deliverables:
1. Input manifest and integrity receipts, missingness and replication audit; abstain if provenance insufficient.
2. Reproduce partner's conventional analysis on identical cases where feasible; report discrepancies and uncertainty.
3. Compare protection-phase and recovery-phase descriptive/statistical models using agreed held-out independent units, no leakage; retain unfavorable and null results.
4. Deliver reproducible scripts, environment/version manifest, report with denominators, limitations and recommendations for independent verification.
5. Technical review meeting and one bounded correction round.

Acceptance: agreed source manifest, executable or explicitly blocked reproduction, agreed metrics and held-out split before analysis, complete report including negatives. Acceptance is based on agreed deliverables, not positive biological effects. Stop if missing provenance, permissions, unsuitable sample independence, or unavailable compute. No contract or price acceptance yet; billing eligibility and written purchasing route must be confirmed. No new spend without approval.
