# OSF pilot 01 — ASTRA external blinded regression challenge
Status: DRAFT / NOT REGISTERED / NOT RUN. No new external data or labels obtained.
Date: 2026-11-27.
## Study purpose
Prospective test of the existing external challenge protocol (v0.18), frozen upstream commit 3f17e01b38745e24f7e05d16bc3116e46a704411, experiments/astra_octopus/external_challenge.py. The historical Grunfeld demonstration was public, not independent or blinded: parent/reference RMSE 36.6029522021, candidate 40.5036124610, REJECT. Preserve this negative evidence. Primary aim is to exercise the independently controlled evidence chain; secondary descriptive endpoint is predictive performance. No claim of novel science or general superiority.
## Participants and data
Independent custodian not yet identified or committed. Before submission of final OSF record: document custodian identity/role, data provenance/licence, prior exposure, acquisition date, group definition, feature list, sample sizes and sampling rationale, environment/dependency versions, exclusion criteria and disclosure permissions. Use a single nonsensitive grouped numeric regression dataset unknown to the model operator; train/validation/test groups disjoint, at least 5 rows per split (software minimum only, not a power calculation). Prefer at least 30 independent test groups for a future adequately powered performance study; do not claim power based on this heuristic. No substitution after outcomes seen. Custodian retains test targets and signing key on separate reviewed machine. Data without clear provenance or independence are ineligible.
## Locked endpoints
Operational PASS only when valid task/label commitment and custodian public key are recorded before predictions, OSF record is approved and verified, independent predictions reproduced, signed receipt verifies and all six negative-control categories below reject. Missing evidence is UNVERIFIED, not PASS. Record all attempts including failures.
Secondary endpoint: existing candidate refit selection vs parent train-only and reference train-only (ridge or histogram gradient boosting), RMSE on all test rows. Existing rule: candidate worse than best comparator -> REJECT; candidate <= 0.99 * best comparator and best > 0 -> ELIGIBLE_FOR_FURTHER_TESTING; otherwise NO_GAIN. Never promote on one task. Report exact RMSE and number of groups/rows; no formal significance claim.
Important design limitation: refit candidate uses more training labels than comparators. This pilot does not isolate interdisciplinary benefit. A later separately registered comparison must include equal-data refitted reference and ablations; do not change the pinned v0.18 algorithm or interpret the pilot as superiority.
## Negative controls and integrity
Before any external run, exercise existing test_external_challenge.py and record environment, command, full result and commit. Negative categories: overlapping groups; visible test labels; changed task or protocol digest; wrong public key; changed private labels; tampered predictions or signed receipt. Positive control: reproducible valid submission and valid receipt. No key or labels in public artifacts. A signature authenticates receipt, not hidden-label accuracy by itself. Independent custodian reports checks and all outcomes.
