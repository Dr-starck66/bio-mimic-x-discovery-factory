# BIO-MIMIC X × CG Oncology — GSE244895 paired BCG transcriptome analysis

**8 November 2026 · PARTIAL (metadata only) · no cost · not a CG Oncology collaboration**

This is a new, isolated validator in the existing `bio-mimic-x-discovery-factory/validation/` family, following the GEO acquisition/provenance approaches of `validation/geo_pair_probe.py` and `validation/run_geo_validation.py` without conflating bulk TPM with count-based normalization or clinical efficacy.

## Actual evidence from public GEO metadata

- 35 samples (13 labelled pre-treatment, 22 labelled post-treatment) from **14 distinct patients**.
- **12 patients have both pre and post samples** (P-11 is post-only; P-14 is pre-only), when grouping by GEO sample names. There is no attempt to count multiple post samples as independent biological patients.
- This is **not yet a gene-expression analysis**. Matrix transfer failed due to DNS/network restrictions in the current execution container.
- Authoritative record: https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE244895
- Matrix: `GSE244895_Bladder_BCG_STAR_RSEM_TPM_raw_.txt.gz` (public processed TPM, approximately 609 KB; **not sequencing FASTQ data**).
- Reproducible real metadata count report: `reports/cretostimogene/gse244895_metadata_qc_2026-11-08.json`.

## On an authorized network executor

```bash
python -m pip install numpy
python validation/cretostimogene_bcg_tpm.py --download
python -m unittest discover -s tests -p 'test_cretostimogene_bcg_tpm.py' -v
```

Optional local matrix: `python validation/cretostimogene_bcg_tpm.py --input /path/to/GSE244895_...gz` (local-file source stays marked `EXPLORATORY_UNVERIFIED_PROVENANCE`, not `EXPLORATORY_GEO_DOWNLOADED`).

The tool checks the gzip, SHA-256, matrix dimension/known cohort IDs, nonnegative finite TPM, unique gene names, patient pairing and marker identifiers. It uses log2(TPM + 1), per-patient averaging of repeated post samples, exact paired sign flips (up to 16 patient pairs), a predetermined 22-gene panel, 2,000 patient-level bootstrap draws, and Benjamini–Hochberg correction within that panel. Its fixed-seed randomized sign control is a placebo exploratory comparison, **not an independent external validation**.

### Exclusion / interpretation gates

- Clinical response to BCG is not inferred from sample timepoint or RNA abundance.
- These data have **no observed treatment with cretostimogene**; this experiment cannot support a cretostimogene-response model or treatment recommendation.
- The matrix may contain Ensembl-only gene IDs: never guess a biological gene name. In this case the analyzer fails closed until an independently verified ID-to-symbol map is available.
- Later post-treatment specimens may be at different timepoints, disease stages or treatment contexts; per-patient averaging controls pseudoreplication but **not confounding**.
- The tests use synthetic fixtures to verify implementation correctness, not to assert disease biology.
