# BIO-MIMIC X V6 — Autonomous Scientific Organization

## Daily organization cycle

Seven specialist labs run independently:
- ONCO-X
- REGEN-X
- NEURO-X
- IMMUNO-X
- LONGEVITY-X
- METABOLIC-X
- PRESERVE-X

Each lab produces a signed JSON artifact with:
- literature sources,
- candidate species,
- mechanisms,
- gene mentions,
- Evidence score,
- Skeptic score,
- Arbiter score,
- challenge flags.

The Scientific Investment Committee then:
1. merges all lab outputs;
2. rewards cross-lab convergence;
3. penalizes weak provenance and challenge density;
4. builds a portfolio;
5. allocates exactly 100 internal research credits;
6. creates cross-lab challenge assignments;
7. stores organization memory;
8. writes a daily report;
9. fingerprints the cycle with SHA-256.

Research credits are priority units, not money.

## Defensibility layer

V6 adds organization-level assets that a code copy does not recreate:
- specialist-lab histories,
- cross-lab convergence history,
- committee decisions,
- challenge history,
- organization memory,
- cumulative portfolio,
- replay fingerprints.
