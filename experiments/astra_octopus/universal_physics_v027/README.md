## Capability registry
Four finite physical contracts: steady flow ratio, pressure-work power, wire-to-water efficiency proxy under declared boundary/head assumptions, three-phase instantaneous electrical power under explicit reference and phase alignment. Unit conversion to SI, provenance measured rather than nominal, unique channel IDs, explicit metadata conditions. Eight tests passed, including unavailable fields, zero power, unsynchronized channels, unit mismatch, nameplate substitution, duplicate channels and unknown boundary. Registry is rule selection only; manually supplied manifest is required, not independently validated by code. No universal equation discovery or autonomous sensor mapping. Registry not integrated with experimental WHUT scoring; WHUT metadata is insufficient for full certified contract. No deployment, no economic valuation or extra costs.
