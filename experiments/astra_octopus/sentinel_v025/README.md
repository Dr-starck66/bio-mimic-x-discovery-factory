## Frozen experiment
Read source feature extraction and label profile before freezing. 21 fully nominal cycles, all in last third; cannot fit and validate a global healthy detector with this ordered split. Target pump leakage only. Train cycles 1–735, known no-leak 407; calibration cycles 736–1470, 23 fully no-leak blocks of 15; final 735 cycles 1471–2205, 407 no-leak and 328 leak (164 weak,164 severe). Other faults may coexist in pump-no-leak labels. All test cycles have cooler label 100; no such label in fit and six cycles in calibration. Stability flag only for audit. No test observations retrieved before commit 109075e96107421b73a9383bd2ef1e5670e45616; blob ac21a78fe4af415e966e12eeb876d5720e0986b2. Reuse v0.24 two-sided CUSUM principle, adapted to ten cycle means, 15-cycle resets, drift .25; same calibration quantile on block maxima, not guaranteed matched test FPR. Robust absolute and within-modality relative scores, max fusion and corroboration candidate. No imputation, reset unavailable channels, abstain below 75% channel availability. A missing relative score is unknown when no relative family can be computed. Unknown fault rows count as misses, unknown normals reported separately. Finite-sample calibration at 23 blocks is empirical, not a coverage proof under regime shift. No forecast of onset/RUL.
## Results
Frozen SENTINEL and absolute, relative, sequential dual CUSUM all 328 TP, 406 FP, 1 TN, 0 FN; 99.75% FPR, 100% recall, 100% coverage. Pointwise dual 328 TP/386 FP. All 21 fully nominal cycles alarmed. Reject. No missing in original selected features. Ten independently generated masks for each 10% and 25% per-channel dropout on test only; same mask for all methods; thresholds calibrated on complete data. SENTINEL mean coverage 92.26%, recall 83.05%, FPR on scored normals 88.13% at 10%; at 25%, 52.61%, 43.41%, 76.07%. Missingness therefore still harms detection. 7 functional assertions on frozen code; exact replay of full complete-data result. Source labels and original cycle order verified.
## Exploratory correction (test exposed)
PS4 train median and MAD both zero, denominator 1e-6; pump-no-leak test PS4 median 8.80488. Training and test cooler regimes differ, with marked temperature shifts. This is a plausible contributor, not causal attribution. Post-audit correction omits PS4 and TS2, models seven means against TS1 using median pairwise slopes, robust intercepts and nonzero scale floors. Temperature context is not assumed exogenous. Same frozen split, conventional CUSUM recalibrated on same residuals. Candidate requires two corroborating feature families. Complete-data corrected SENTINEL: 210 TP, 137 FP, 270 TN, 118 FN; FPR 33.66%, recall 64.02%. Corrected absolute CUSUM 253 TP,193 FP (77.13% recall,47.42% FPR). Candidate reduces FP relative to original 406 by 66.26%, with sensitivity loss; relative to corrected CUSUM by 29.02%, with sensitivity loss. Five masks at 10% dropout: corrected SENTINEL mean recall 13.23%, coverage 88.63%, scored-normal FPR 3.68%; missing-induced reset means low FPR is not a benefit. Complete-data correction replay identical. No promotion or economic benefit. Correction is exploratory, not unseen validation. No deployment.
